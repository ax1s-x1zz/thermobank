# thermobank

**저온 폐열을 위한 열화학 에너지 저장 반응 스크리닝.**

thermobank 는 하나의 질문에서 출발한다. *어떤 온도의 폐열이 주어졌을 때,
그 열로 어떤 가역 화학 반응을 구동할 수 있고, 얼마나 많은 에너지를 저장할
수 있는가?* 고등학교 화학에서 배우는 열역학(`dG = dH - T dS`)으로 탈수·분해
반응 후보들을 스크리닝하고, 각 반응이 자발적으로 진행되는 문턱 온도
`T* = dH / dS` 를 계산한다.

동기는 구체적이다. 데이터센터는 액침 냉각 랙에서 60~90 ℃의 저온 폐열을
대량으로 버리고, 산업계는 150~200 ℃에서 더 많이 버린다. 이 열을 그냥
버리지 않고 화학적으로 저장하는 것은 활발한 연구 분야다(염 수화물·수산화물
루프, 제올라이트 흡착 배터리).

## 빠른 시작

```bash
pip install -e .
thermobank screen --csv results/screening.csv
thermobank reaction gypsum --temp 80
```

## 계산하는 것

| 모듈 | 값 |
|---|---|
| `thermo` | 반응 `dH`, `dS`, `dG(T)`, 문턱 온도 `T*`, 에너지 밀도 |
| `screen` | 모든 후보를 데이터센터·산업 폐열 구간에 대해 순위화 |
| `kinetics` | 아레니우스 상대 속도 — 자발성과 속도는 다르다 |
| `calorimetry` | 간단한 열량 측정으로부터 몰 용해열 계산 |

## 방법 (한 줄)

`dG(T) = dH(298) - T dS(298)`. `dH > 0`, `dS > 0` 인 탈수 반응은
`T* = dH/dS` 이상에서 자발적이다. 교육과정에서 쓰는 근사이며 `T*` 를 수십 도
이내로 맞춘다. 자세한 내용은 `docs/methods.md`.

## 데이터 출처

표준 생성 데이터는 CRC Handbook 과 NIST Chemistry WebBook 에서 가져왔다.
염 수화물 값은 `approx` 로 표시했고 불확실성이 더 크므로, 그에 의존하는
결과는 따로 표시한다. `src/thermobank/data.py` 참고.

## 한계

* `dH`, `dS` 를 온도 무관으로 취급한다.
* 수화물 열역학 데이터는 기체·고체 데이터보다 확립도가 낮다.
* 열역학적 타당성은 반응 속도, 물질 이동, 사이클 안정성을 포함하지 않는다.
